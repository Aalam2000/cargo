📦 Инструкция по работе с платформой

Платформа Cargo предназначена для ведения работы карго-компании: справочники, товары, грузы, начисления и оплаты.

Правильный порядок работы в системе простой: сначала настраиваются справочники, затем ведётся операционная работа по товарам, грузам и финансам.

📚 1. Справочники

Перед началом работы нужно заполнить и назначить основные справочники компании.

  • склады;
  • типы грузов;
  • статусы грузов;
  • типы упаковки;
  • типы начислений;
  • типы оплат;
  • тарифы и связанные параметры.

📦 2. Создание товаров

После настройки справочников создаются товары клиентов.

  • выбирается клиент;
  • заполняется описание товара;
  • указываются тип, упаковка, склад, вес, объём и другие параметры;
  • при необходимости формируются данные для документов и QR-кода.

🚚 3. Сборка грузов из товаров

Созданные товары объединяются в грузы.

  • товары подбираются в один груз;
  • груз получает собственный код;
  • по грузу задаются статус, склад и дальнейшее движение;
  • при изменении груза данные синхронизируются с товарами внутри него.

💰 4. Начисления клиенту

После оформления товаров и грузов в систему вносятся суммы начислений клиенту.

  • выбирается клиент;
  • указывается тип начисления;
  • фиксируется сумма;
  • при необходимости указываются комментарии и дополнительные данные.

💳 5. Оплаты от клиента

После начислений в систему заносятся оплаты от клиента.

  • указывается клиент;
  • фиксируется дата оплаты;
  • выбирается способ оплаты;
  • сохраняется сумма и валюта;
  • баланс клиента обновляется в системе.

✅ Итог

Рабочая схема платформы:

  • заполнить справочники;
  • создать товары;
  • собрать грузы из товаров;
  • внести начисления;
  • внести оплаты;
  • контролировать движение, статусы и расчёты.
