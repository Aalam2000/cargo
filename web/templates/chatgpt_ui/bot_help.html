🤖 Инструкция по работе с ботом

Telegram-бот Cargo помогает работать с платформой и выполнять основные действия без поиска нужных разделов вручную.

Ссылка на бота: @cargo_adm_bot

Бот понимает два основных режима работы:

  • Telegram не найден в системе — бот считает, что это новая компания.
  • Telegram найден в системе — бот считает, что пользователь уже работает в компании.

🏢 Если Telegram не найден

В этом режиме бот:

  • объясняет, как работать с ботом;
  • объясняет, как работать с платформой;
  • создаёт новую компанию в системе.

Для создания компании отправьте боту сообщение, где указаны:

  • название компании;
  • email главного администратора;
  • Telegram главного администратора — если есть.

Пример:

Создать компанию "Bona Cargo", admin email: admin@example.com, telegram: @bonacargo

👤 Если Telegram найден

В этом режиме бот:

  • объясняет, как работать с ботом;
  • объясняет, как работать с платформой;
  • создаёт клиента;
  • создаёт пользователя компании.

Отчёты по клиентам, пользователям и рабочим данным компании будут подключены позже.

✉️ Примеры запросов боту

  • Помощь
  • Как работать с платформой?
  • Как создать компанию?
  • Создать клиента client@example.com
  • Создать пользователя user@example.com

📌 Ограничение работы бота

Бот отвечает только по работе в Cargo: создание компании, создание клиента, создание пользователя компании и помощь по работе в системе.
